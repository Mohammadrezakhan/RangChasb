این نسخه برای GitHub Actions آماده شده است.

مراحل:
1) در GitHub یک Repository بسازید (ترجیحاً Public برای استفاده رایگان استاندارد Actions).
2) فایل‌های داخل این ZIP را در ریشه Repository قرار دهید؛ خود فایل ZIP را آپلود نکنید.
3) وارد Actions شوید.
4) workflow با نام Build RangChasb APK را انتخاب کنید.
5) Run workflow را بزنید.
6) بعد از اتمام Build، در صفحه اجرای workflow بخش Artifacts فایل RangChasb-debug-APK را دانلود کنید.

GitHub Actions برای repositoryهای عمومی با runnerهای استاندارد رایگان است.
