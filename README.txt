رنگ و چسب - نسخه 1 برای Online APK Builder

این پروژه عمداً با Java و Android SDK استاندارد ساخته شده و هیچ کتابخانه خارجی مثل
Jetpack Compose یا کتابخانه‌های Maven اضافی ندارد تا برای سرویس‌های آنلاین APK Builder
ساده‌تر باشد.

امکانات:
- نمایش کالا
- جستجو
- افزودن کالا
- دسته‌بندی
- قیمت
- موجودی
- تغییر قیمت با لمس کالا

در سایت Mevada Labs فایل ZIP را مستقیماً آپلود کنید و Build APK را انتخاب کنید.

اگر سرویس خطای "Failed to fetch" داد، این خطا می‌تواند از دریافت ابزار/وابستگی‌های
سمت سرور همان سرویس باشد، نه لزوماً از کد پروژه. در آن حالت متن کامل خطا یا
گزارش Build لازم است.
